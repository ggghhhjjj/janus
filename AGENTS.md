# Agent Instructions — Janus (Angular + Cordova browser PWA)

## Project Overview

Apache Cordova app targeting the **browser** platform, with **Angular 21** as the UI framework. Janus is an **organizer**: it wires libraries from `dynamic-components` and must not define its own UI widgets.

- Angular source: `src/` — **always edit files here**
- Build output: `www/` — generated by `npm run build` (Angular), do not edit
- Cordova output: `platforms/browser/www/` — generated by Cordova, do not edit
- App config: [`config.xml`](config.xml)
- Dependencies: [`package.json`](package.json)

## Key Source Files

| File | Purpose |

| `src/app/core/i18n/` | Runtime i18n (`locale-url.ts`, `translations.ts`, `locale.service.ts`) |
| `src/app/core/update/app-update.service.ts` | Refresh = unregister SW + clear caches + reload |
| `src/styles.css` | Global reset only — no component look |
| `public/` | Static assets copied into `www/` (`cordova.js` stub, manifest, favicon) |

| `angular.json` | Angular CLI config — output path is `www/`, project name `janus` |
| `hooks/before_prepare/build_angular.js` | Cordova hook — runs `npm run build` before every prepare/build/run |

## ui-header dependency

Janus imports `UiHeader` as an Angular library, not the `elements-host` web-component bundle:

```json
"ui-header": "file:../dynamic-components/dist/ui-header"
```

Build the library **before** `npm install` / `npm ci` in `janus/`:

```bash
cd ../dynamic-components && npm ci && npm run build:ui-header
cd ../janus && npm ci
```

Do **not** add local UI components (`app-header`, Dashboard widgets, etc.). Compose `dynamic-components` libraries in `app.ts`.

## Runtime i18n

No `@angular/localize` and no compile-time locale builds. Labels update at runtime:

- `AppLocale = 'bg' | 'en'` — Bulgarian default, English second
- Storage key: `localStorage['janus-locale']`
- Priority: stored locale → `<html lang>` → `bg`
- `LocaleService.setLocale()` persists, syncs `<html lang>`, and updates the `locale` signal
- Header display codes are `BG` / `EN`; the shell maps `bg↔BG`, `en↔EN`

Add every visible string to `translations.ts` (`BG` is the key source of truth).

## PWA / Refresh

- Service worker is production-only (`provideServiceWorker` + `isDevMode()`). `ng serve` does not register it.
- Manifest: `public/manifest.webmanifest`
- **Refresh** (header menu) calls `AppUpdateService.reloadApp()`: unregister service workers, delete Cache API caches, then `location.reload()`. That is the update path for the offline PWA.

## Build & Run Commands

```bash
# Install all dependencies (first time or after package.json changes)
npm install

# Build Angular app into www/
npm run build

# Unit tests (Vitest)
npm test

# Serve and open in browser (hook runs ng build automatically)
npm run cordova:run

# Build Cordova for browser (hook runs ng build automatically)
npm run cordova:build

# Prepare only (hook runs ng build automatically)
npm run cordova:prepare
```

> Requires `cordova` CLI installed globally: `npm install -g cordova`

`npm start` runs `ng serve` for live reload (service worker off).

## How It Works

1. `cordova run browser` (or build/prepare) fires the `before_prepare` hook
2. The hook runs `npm run build` → Angular CLI compiles `src/` → output lands in `www/`
3. Cordova copies `www/` → `platforms/browser/www/` and serves it

## Angular Conventions

- **Standalone components** (no NgModule). All components use `imports: []` directly.
- **Signals** for local reactive state (`signal()`, `computed()`).
- Component files follow Angular 17+ naming: `app.ts`, `app.html`, `app.css` (no `.component.` infix).
- `CordovaService` (`src/app/cordova.service.ts`) is the single point of access for `deviceready`.
- **No local UI widgets** — Janus organizes `dynamic-components` libraries only.
- Responsive layout is **CSS only** (BEM + `@media`). No `matchMedia` / resize listeners.

## Cordova Conventions

- **Always use `CordovaService.deviceReady$`** instead of adding raw `deviceready` listeners.
- `cordova.js` is injected by the platform at runtime — it is declared in `src/index.html` but
  the actual file is provided by `cordova-browser` during the Cordova prepare step.
- CSP is set via `<meta http-equiv="Content-Security-Policy">` in `src/index.html`.
- Plugins are added via `cordova plugin add <plugin-id>` and declared in `config.xml`.

## Tests

Vitest via `ng test` (`@angular/build:unit-test`). Specs live next to the code (`*.spec.ts`):

- `src/app/app.spec.ts` — shell renders `ui-header` and the Dashboard tab
- `src/app/core/i18n/locale-url.spec.ts` — `detectLocale` priority
- `src/app/core/i18n/locale.service.spec.ts` — persist, `text()`, `setLocale`
- `src/app/core/update/app-update.service.spec.ts` — SW unregister + cache clear + reload

## Common Pitfalls

- **Never edit `www/` or `platforms/browser/www/`** — these are auto-generated. Always edit `src/`.
- **`cordova.js` is NOT a file** — it's injected at runtime by the Cordova platform. Don't move or rename the `<script src="cordova.js"></script>` tag.
- **Forget to check CSP** — if APIs fail silently, verify the `<meta http-equiv="Content-Security-Policy">` in `src/index.html` allows the origin.
- **TypeScript `cordova` object is undefined in dev** — use the `typeof cordova !== 'undefined'` check in `CordovaService` to avoid compile-time errors in the browser.
- **`file: ui-header` missing** — build `dynamic-components` (`npm run build:ui-header`) before installing Janus deps.
- **`file: ui-header` is a symlink** — `angular.json` sets `preserveSymlinks: true` so the app and the library share one `@angular/core`.

## Development Tips

- **Hot reload**: `npm start` runs `ng serve` for live reload during development (before Cordova integration).
- **Debug in browser**: Open `http://localhost:4200` during `npm start` to inspect the app with DevTools.
- **Cordova command chain**: `npm run cordova:run` automatically runs the hook → builds Angular → serves. Use it for end-to-end testing.
- **Static assets**: Place images and media in `public/`. The build copies them to `www/`.
- **Platform-specific logic**: Use `this.cordova.platformInfo` (e.g., `cordova-browser`) to branch on platform inside components.

## TypeScript & Angular Specifics

- **No `node_modules` in `www/`** — Angular bundler tree-shakes and minifies everything. Browserify/webpack config is in `angular.json`.
- **Standalone component default** — always use `standalone: true` and import dependencies directly in `imports: []`.
- **Signals over manual subscriptions** — prefer `signal()` and `computed()` for local state; use `CordovaService.deviceReady$` for one-time async setup.
- **Async pipe in templates** — safe way to subscribe to observables in templates without memory leaks.
